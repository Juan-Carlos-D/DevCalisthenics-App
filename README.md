# NovaFit: Scalable Fitness App with AI Chatbot

## Purpose & Goal

NovaFit is a full-stack web application designed to help fitness enthusiasts track their exercise and nutrition goals. The app provides personalized advice, guidance, and support for users on their fitness journey. It includes an AI-powered chatbot that assists with various fitness-related queries and offers a macronutrient calculator to calculate users' nutritional needs. The primary goal of this project was to create an intuitive, scalable solution to assist users in achieving their fitness and wellness objectives.

## Features

- **Personalized Fitness Assistance**: Get fitness and nutrition tips from an AI-powered chatbot, built using Chatbase.co, which handles over **30 user queries per month**. The chatbot offers tailored advice on exercise routines, diet, and overall fitness goals.
- **Macronutrient Calculator**: A tool to calculate daily macronutrient requirements based on user preferences and goals. **Over 2000 calculations performed** since launch, helping users understand their nutritional needs more accurately.
- **Exercise Guidance**: A comprehensive library of **over 100 workout instructions**, including detailed explanations and visual guides, to help users work out efficiently and safely.
- **Responsive Design**: The app is built to provide a smooth experience across different devices, achieving **95% mobile responsiveness** across various screen sizes using HTML, CSS, and JavaScript for the frontend.
- **User Engagement**: Increased user engagement by **30%** due to the integration of the AI chatbot, which offers 24/7 personalized fitness support.

## Technologies Used

- **Backend**: Flask, Django, Python
- **Frontend**: HTML, CSS, JavaScript
- **AI Chatbot**: Chatbase.co, integrated to handle **automated interactions and FAQs**, improving user experience and reducing the need for manual assistance.
  
## Future Improvements

- Adding user authentication for personalized accounts.
- Integrating more advanced features for nutrition and exercise tracking.
- Expanding the chatbot’s capabilities with additional fitness data and knowledge to provide even more tailored guidance.
- Enhancing the macronutrient calculator with more detailed options and support for different dietary plans (e.g., keto, vegan).
